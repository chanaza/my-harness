# Adapters

One folder per tool. Each adapter will provide:

- `README.md`: what this tool can and cannot capture (its tier), verified.
- Install steps: how to load the harness into the tool.
- Capture: the hook, skill or instruction that saves compactions,
  summaries, memory and live logs back through the engine.
